Cut your AI coding bill

Trim terminal output, wordy replies and MCP payloads with three free tools for Claude Code.

Adi3 min read

Old command output and tool results can add to the cost of later requests. Caching and compaction affect the bill, but trimming noise before it reaches the conversation still helps.

Terminal output

RTK

A CLI proxy that compresses shell output before the model sees it. It strips colour codes, collapses repeated lines and trims noise while keeping errors.

A git status that costs about 2,000 tokens comes back at about 200. The project reports 60–90% savings on common commands. It's a single Rust binary that works with Claude Code, Cursor, Codex CLI and Gemini CLI.

rtk-ai.appGitHub
Install
# Bash / macOS / Linux / WSL
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh
rtk init -g --hook-only
Model replies

Caveman

A Claude Code skill by Julius Brussee that makes prose replies terse: fewer pleasantries, less hedging and fewer unrequested explanations.

The README reports 65–75% fewer output tokens on prose, for example 294 tokens per reply instead of 1,214. /caveman ultra compresses further, and a companion tool shrinks your CLAUDE.md by about 46%.

GitHub
Install
npx skills add JuliusBrussee/caveman
MCP payloads

Context Mode

Useful for large MCP results from tools like Playwright, Google Drive or GitHub. In the project's examples, a Playwright snapshot is 56 KB and twenty GitHub issues are 59 KB.

Context Mode, by Mert Köseoğlu, stores raw tool output in a local SQLite database and returns a short summary you can search later. Its benchmark shrinks 315 KB to 5.4 KB. It also saves session state, so the agent stays on track after compaction.

GitHub
Install
claude mcp add context-mode -- npx -y context-mode
