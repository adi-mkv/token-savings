Three Free Tools That Cut Your AI Coding Bill

Every terminal command, every MCP call, every verbose reply is burning tokens. These tools fix that.

A
Adi 3 min read  ·  June 2026

Every time Claude Code runs a command, reads a file, or calls an MCP tool, the raw output lands in your context window and stays there — compounding on every turn. By message 40 of a real session you're paying to re-read thousands of tokens of terminal noise that stopped being useful 30 minutes ago.

Three tools fix this. Each targets a different source of waste: noisy terminal output, verbose model responses, and bloated MCP payloads. Stack them and you can run hours-long sessions without the bill spiralling.

01 / 03

RTK

↗ rtk-ai.app ↗ GitHub
INSTALL 
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh
rtk init -g --hook-only

RTK (Rust Token Killer) is a CLI proxy that intercepts shell commands and compresses their output before it ever reaches the model's context. When Claude Code runs git log, cargo test, npm install, or any other terminal command, RTK strips ANSI codes, collapses repeated log lines, groups related output, and truncates the noise while keeping errors intact. A raw git status that costs ~2,000 tokens comes back at ~200. The project benchmarks 60–90% savings across common dev commands, with one 30-minute TypeScript session dropping from 118,000 tokens to 23,900. It's a single Rust binary, MIT licensed, zero dependencies, and supports Claude Code, Cursor, Codex CLI, Gemini CLI, and a dozen other tools.

02 / 03

Caveman

↗ GitHub
INSTALL 
npx skills add JuliusBrussee/caveman

LLMs are trained to be helpful and thorough, which means they pad. Caveman is a Claude Code skill by Julius Brussee that enforces a compressed output style — no pleasantries, no hedging, no unsolicited explanations. Just code and results. The README benchmarks 65–75% fewer output tokens on prose responses, with a real test showing 294 tokens per response against 1,214 in normal mode. Code quality is unaffected; only the filler gets stripped. It also ships with intensity levels (/caveman ultra for maximum compression), a companion tool that rewrites your CLAUDE.md memory file into compressed form (cutting ~46% of input tokens per session start), and an experimental Wenyan mode using Classical Chinese for further compression. The repo crossed 50,000 GitHub stars within two weeks of launch.

03 / 03

Context Mode

↗ GitHub
INSTALL 
claude mcp add context-mode -- npx -y context-mode

If you use MCP tools like Playwright, Google Drive, or GitHub, this one is the most impactful. Every MCP call dumps its full raw payload into your context window and it stays there for the rest of the session. A single Playwright snapshot costs 56 KB. Twenty GitHub issues cost 59 KB. One access log: 45 KB. Context Mode is an MCP server by Mert Köseoğlu that sits between Claude Code and those tools — intercepting calls, storing raw output locally in a SQLite FTS5 database, and returning only a concise summary to the conversation. The raw data stays addressable for follow-up queries via full-text search, but it never bloats the context. The benchmark: 315 KB of raw output compressed to 5.4 KB visible context — a 98% reduction. It also tracks session state in SQLite so that when the conversation compacts, the agent doesn't lose track of what it was doing.

Stack all three and you're covering every major source of token waste: terminal noise (RTK), verbose model output (Caveman), and MCP payload bloat (Context Mode).
